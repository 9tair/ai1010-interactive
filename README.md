# AI1010 interactive labs

Interactive classroom demos for the AI1010 (Intro to AI) labs, published with GitHub Pages:

- Lab 4, probability playground (Week 5): https://9tair.github.io/ai1010-interactive/lab4/

Each page is a single self-contained HTML file with no external dependencies. The source of `lab4/index.html` is `lab_4/playground/index.html` in the (private) labs project, so update both together. Add `?selftest` to the address to run the built-in checks.
